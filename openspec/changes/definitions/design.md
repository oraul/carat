# Design

## Context

`K` already asks the language server asynchronously: `RequestHover` records an ask in the shared `HoverRequest`, `JsonRpcLanguageGateway#poll` sends it at the next idle tick (`send_hover`), cancels a stale one with `$/cancelRequest`, keeps the answer, and sets `arrived`; `InputController` then calls `ShowHover`, and `HandleKey` runs `FollowHover` after a key only while its float is recorded. Files open through `OpenFile` (the `:e` path), whose only refusals are a directory, a non-regular file, and a file over 64 MiB; it has no root check. The project-root check with links resolved is `ResolveInside`, used by the plugin file requests. A scratch buffer (an owner, no path) is never written: `SaveFile` refuses it with E382. A scratch buffer may carry its own keymap, which `HandleKey#lookup` consults first. No jump list exists; Ctrl-O and Ctrl-I are unbound.

## Goals / Non-Goals

Goals: `gd`, a peek float, a pick list for several targets, and a jump list with Ctrl-O and Ctrl-I, on the hover request's asynchronous path; Neovim's messages; safe handling of untrusted target paths; no cost per key while nothing shows (`lh` 27.0, `j` 28.0, `insert` 35.0 held).

Non-goals: other jump commands in the jump list, a per-window jump list, `:jumps`, other location requests, a quickfix list.

## Decisions

- One shared record, `Domain::DefinitionRequest`, mirrors `HoverRequest`: the anchor (window, buffer, row, col), `want`, `sent`, `sent_id`, `language`, `deadline`, `peek` (the kind of the latest ask), `arrived`, `languages` (servers advertising `definitionProvider`), the targets as parallel arrays (`paths`, `lines`, `characters` in UTF-16 units), `float_id` (the peek float), and `pick_id` (the pick list). It is built once in `EditorAssembly` and held by the gateway and the use cases.
- The gateway sends `textDocument/definition` like the hover: once per ask, only in normal mode with the anchor unchanged, one request in flight, cancelled by a newer ask or after `ANSWER_LIMIT` (2 s). Unlike the hover (whose stale-answer defect is queued in `hover-tidy`), an answer is dropped unless no newer ask was recorded since it was sent (`sent == want`). The answer may be a `Location`, a list of them, or a list of `LocationLink`s (`targetUri`, `targetSelectionRange`); `linkSupport` is advertised. Only `file:` URIs are kept, percent-decoded; a decoded path that is not absolute, holds a NUL, or exceeds 4,096 bytes is dropped; at most 50 targets are read, and a line or character that is not a non-negative integer drops the target.
- `RequestDefinition#call(state, peek)` refuses a buffer with no path or no offering server with Neovim's `method textDocument/definition is not supported by any of the servers registered for the current buffer`, else records the ask. `ShowDefinition#call(state)` runs at the idle tick when `arrived`: it drops an answer whose anchor no longer holds or that arrives outside normal mode, closes an older peek float or pick list, shows `No locations found` for none, visits the one target, or opens the pick list.
- `VisitTarget#call(state, index)` is the shared logic `ShowDefinition` and `ChooseDefinition` call (section 5: shared logic needing other use cases stays a use case). For a jump: the same buffer moves the cursor; another file is refused with E37 when the current file buffer is modified; a target inside the project (`ResolveInside` on the working directory with the target path itself, so a link leading out counts as outside) opens through `OpenFile`; one outside opens as a scratch view owned by `:definitions`, titled with the path, its text read through `ProbePath` and `FilePort#read` with the refusals `OpenFile` shares through `Domain::PathInfo#refusal` and its 64 MiB `PathInfo::BUFFER_LIMIT`, its file type detected from the path, reused when a view of that path is listed. The position left is pushed to the jump list only once the target is shown, then the cursor goes to the target line (clamped) and the code point column of the UTF-16 character (clamped to the line), the cursor counting columns in characters. For a peek: the lines come from a listed buffer of that path or a read of at most 8 MiB; the float shows at most 12 rows from the target line, bordered, titled `path:line`, below the cursor or above when there is more room, z 50, not entered, its buffer carrying the file type as its syntax.
- The pick list is an entered, bordered float over a scratch buffer owned by `:definitions` whose own keymap binds `normal <CR> definition.choose`, so Enter chooses only there; `j`, `k`, and the window's other keys move in it and Esc closes it (`float.close`). `ChooseDefinition` reads the float window's cursor row, closes the list, and visits that target with the ask's kind.
- `FollowDefinition` runs after a key only while `float_id` or `pick_id` is set (one integer test per key otherwise, as `FollowHover`): it forgets a float another path closed, closes the peek float when the layout cursor left the anchor or the mode is not normal, and closes the pick list when it is no longer the focused window.
- `Domain::JumpList` holds parallel arrays of buffer ids, rows, and columns and an index equal to the length when no entry is current. `push` removes an entry of the same buffer and row, appends, keeps the last 100, and moves the index to the end; `step(by, buffer, row, col)` with a negative `by` from the end first pushes the current position; it answers the entry index reached or -1 out of range, moving nothing then. `WalkJumps#call(state, steps)` shows the entry's buffer (`BufferList#load`, E37 for a modified current file buffer), drops an entry whose buffer is gone, and clamps the row, then the column with `EditorState#clamp_col`.
- `DefinitionHandler` registers `definition.jump`, `definition.peek`, `definition.choose`, `jump.older`, and `jump.newer` (kind `:action`, not repeated; the count reaches `jump.*`).

## Risks / Trade-offs

- [A server returns a path to a device or a huge file] → the read goes through the stat refusals and the read limit, as `:e` does.
- [A server points outside the project to make the user edit and save a system file] → such targets open as scratch views, which are never written.
- [The gateway grows] → the new methods mirror the hover's; folding the copies is `hover-tidy`'s.
- [An editor-wide jump list differs from Neovim's per-window one] → recorded in the proposal; a later change can move it into the window.
