set-options: the user's decision of 2026-11-21 (the design council, decision 2 approved: the basics ahead of the remaining Facet waves; the 'Final 2026-11-21' user-request note on listchars-folds), Sprint 26 feature item 1 in docs/queue-feature.md (placed by sprint-25-records, #285), ahead of `buffer-picker` and `folded-row`; where its queue entry and this brief differ, the queue entry's Where lines locate the code and this brief's scope stands. Touch no file of the backlog lane (docs/queue-backlog.md, docs/metrics-backlog.tsv). No model name or alias anywhere in names or prose. If the change edits tools/rules.sh, stop and name it.
Why: the design council's carat user found that options can be changed only by editing .caratrc and restarting: `:set` handles only filetype, syntax, the four search options, and cursorline, and answers `Not implemented: :set name` for every other option the editor has (carat/use_cases/ex/set_command_handler.rb PENDING, docs/compatibility.md ':se[t]' row and the Options section); there is no `:colorscheme` (docs/compatibility.md Themes: 'The theme is read once at startup'); and `:e`/`:b` refuse a modified buffer as Neovim does with 'hidden' off, while closing a window already keeps one hidden, so switching files with unsaved work means writing first.
The change, as Neovim 0.10 does it: (1) `:set` for every option in PENDING, by its full and short names: the numbers (`tabstop`, `shiftwidth`, `scroll`, `scrolloff`, `timeoutlen`, `undolevels`, `showtabline`/`stal`) as name=N, name+=N, name-=N, name^=N, and name?, each checked by the same range rule and message as its configuration line (an invalid value is E474 or E521 as Neovim words it and keeps the old value); the booleans (`number`, `relativenumber`, `expandtab`, `autoindent`, `list`, and the others that are true/false) in Vim's boolean forms as the search options already take them; the words (`listchars`, `winborder`, `icons`, `breadcrumbs`, `startscreen`, `reducedmotion`, `background`, `theme`) as name=value and name?; `name&` resets to the shipped default; a bare `:set` lists the options changed from their defaults, `:set all` every option; the change shows at once (the frame redrawn, the window's view and number column recomputed), and an option read only at startup that this change cannot apply live answers `Not implemented: :set name live` and is listed under Differences; (2) a new global option `hidden` (`hid`), on by default in config/default.caratrc (`option.hidden true`, mirrored by `make gen-config`), read from the configuration and `:set`: on, `:e`, `:b`, `:bn`, `:bp`, `:bN`, `:bfirst`, `:blast` leave a modified buffer hidden instead of refusing it with E37, and `:q`/`:qa` still name a modified hidden buffer as today; off keeps today's refusals; (3) `:colo[rscheme] [name]`: with a name from Themes::NAMES, switches the palette at once (every group repainted, the 256 and 16 color mappings as at startup), `E185: Cannot find color scheme 'name'` for another name, and with no name shows the current one; Tab completion of the names at the `:` prompt if cmdline-editing's completion is on main; `:set theme=name` does the same; (4) config/default.caratrc comments, docs/compatibility.md (the :set row split per kind, a :colorscheme row, the Options section's 'from the option.* lines only' sentences and every 'Not implemented: :set x' Difference updated), docs/actions.md if a key is added (none expected), README's options section; (5) a table-driven test per option kind and form: each number with =, +=, -=, ^=, ?, an out-of-range value, and &; each boolean form; each word value and an invalid one; bare :set and :set all; hidden on and off for :e and :b over a modified buffer and :qa naming it; :colorscheme with each shipped name, an unknown name, and no name, the frame's groups repainted. Accepted when make stages pass, `lh` holds 25.0, `j` 26.0, `insert` 25.0, every ADDED and MODIFIED scenario names its test, and no option is changed by :set to a value its configuration line would refuse. The planner may split it by its 3-part rule (:set for the existing options; hidden; :colorscheme). Backlog: none.
