# Brief

A blocking security finding (T0, front of the queue) still open on main since #100, and the user's decision on how to close it. The finding (Medium, confidence 8, from the periodic review after #100): core.hooksPath points at the tracked .githooks directory (Makefile, the hooks target that make toolchain runs), so checking out any branch that commits an executable .githooks hook runs it. The attempt to keep local hooks safely (hooks-path-fix, PR #101, open, not merged) stopped after three fix rounds, each install scheme opening a new hole: hooks checked by name only, then bypassable with git replace refs, then any old hook version accepted. The user's decision: remove the local commit hooks entirely. Deliver exactly this, from origin/main, nothing more: remove the .githooks directory, the make hooks target and its call from make toolchain, and every setting of core.hooksPath; the guard and the origin gate refuse any core.hooksPath and any non-sample file in the git directory's hooks folder again, as before #100; keep tools/scan_text.sh, the push and merge gates, and the pull request scan; fix the pull request scan so it runs the base commit's scanner (checked out to a separate path with persist-credentials false) over the head's title, body, commits, and added lines, so a pull request that edits the scanner cannot pass its own check (a Low (5) from the same review); update CLAUDE.md (the hard rule naming the hooks, and the Commands line for hooks), the README, and the code map. Tests: a case that a clone after make toolchain has no core.hooksPath, a case the guard and origin gate refuse one, and a case that the scan uses the base's scanner. For the planner: record that this supersedes hooks-path-fix (PR #101 to be closed unmerged, its run abandoned) and that the replace-refs Medium (5) (set GIT_NO_REPLACE_OBJECTS=1 wherever trusted tooling reads origin/main, refuse refs/replace) goes to the backlog under guard-lows; keep the queue's order after this change (backlog-split next, from tmp/briefs/pipeline-cost.md).
