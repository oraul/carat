# Proposal

## Why

`SPINEL_REF` pins Spinel at f34005bf, set by #95 (spinel-bump) on 2026-11-10, and upstream has moved 878 commits since: its head is 6b43fe94de957419fd6a670fae365987b40d4f1a (2026-11-14). The user asked for the bump to that head in its own pull request, as the Makefile and `CLAUDE.md` require, with the vendored header regenerated by `make spinel-header`, the toolchain rebuilt by `make toolchain`, and every stage of `make check` passing.

## What Changes

- `SPINEL_REF` moves from f34005bfded9f66dc094ac0aae85efd541cef789 to 6b43fe94de957419fd6a670fae365987b40d4f1a, upstream head at the start of this change.
- `tools/spinel/spinel_rt_responds_generated.h` is regenerated at the new pin with `make spinel-header`, run with the f34005bf toolchain before `make toolchain`.
- Whatever carat needs to stay green at the new pin (build, tests, `spinel-doctor`, allocation budget, metrics), and nothing else.

No editor behavior changes.

- `Makefile`: `SPINEL_REF`.
- `tools/spinel/spinel_rt_responds_generated.h`: regenerated.

Outside the roadmap of `docs/architecture.md` section 12: a toolchain bump the user asked for, done in its own pull request as the Makefile requires.
